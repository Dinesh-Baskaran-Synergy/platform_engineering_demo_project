# Security and Compliance

AcmeCloud is SOC 2 Type II certified and ISO 27001 certified.
All customer data is encrypted at rest with AES-256.
All traffic is encrypted in transit with TLS 1.2 or higher.
Security vulnerabilities can be reported to security@acmecloud.example.
AcmeCloud runs a bug bounty program for responsibly disclosed vulnerabilities.
